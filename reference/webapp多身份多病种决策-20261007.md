# 暖哨 Web App：多身份、多患者、多病种

首版日期：2026-10-07；最近更新：2026-10-08。以下分轮记录，最新视觉规则以末节和 DESIGN.md 为准。状态：已实现的本地演示版。来源：本次用户逐轮确认与最终实施指令。

## 已确认决策

- 入口为病人、病人家属、医生三种演示身份。病人绑定 p1；家属、医生可浏览三位虚拟患者。
- 家属可代录多人，记录保留录入人。医生业务只读；浏览状态独立，不改变患者记录或提醒状态。
- 首页包含 greeting、status、warning、病种监控 sections、todo、最近事件。导航：首页／记录／＋／趋势／照护；医生隐藏＋及全部写入口。
- 中央加号：新监控、常规检测、新事件。事件含服药、打针、输液、住院、出院、复诊、调药、其他。
- 住院仅为事件标签，不形成全局状态。不根据一次入出院事件推断其他记录背景。
- sJIA、MAS、心脏基础、糖尿病预设可选指标。指标库＋自定义数值、是非、文字；自定义指标不获得自动医学阈值。
- 同一患者共享指标只保存一次；记录按 ID 追加或修改，同一天不覆盖。无时刻不伪造测量时间。
- 新病种只做记录和趋势，不套用 MAS 规则；预设不是诊断。
- 本地身份属于演示流程，不是认证。Store 对医生和跨患者写入拒绝；真实产品仍需服务端认证和授权。
