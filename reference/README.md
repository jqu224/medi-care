## 关键事实速记（做方案前必读）

- **静态监测**：单次指标评分，依据 2016 PRINTO/ACR/EULAR（铁蛋白>684 + 任意2条：血小板<181/AST>48/TG>156/纤维蛋白原<3.6）、2004 HLH-5/8、MS 评分表（≥−2.1）
- **动态监测**（本项目灵魂）：≥2 次输入看趋势不看单点；**预警灵敏度可调、指标权重可自定义、核心/一般指标分级**——这三条可配置性是 PRD 明文要求，别做死
- 监测指标口径（2023 EULAR/PReS）：持续发热、脾大、铁蛋白、血细胞计数/血小板、AST 等肝功、凝血/纤维蛋白原、甘油三酯、LDH、中枢神经受累、出血现象、关节炎
- 明确定位边界：**辅助预警工具，不替代专业诊疗判断**——演示与答辩全程挂这句话
- 用户对象：患者家属 + 地方医生（后者常等标准全符合才干预，是要被「预警」改变的行为）
