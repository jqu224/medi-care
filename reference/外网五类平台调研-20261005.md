# 外网五类平台调研 + UI 设计思考（2026-10-05）

> 五类：①医患平台 ②医药管理平台 ③个人健康管理平台 ④警报平台 ⑤助人平台。
> 重点：警报平台是项目7的"灵魂类目"——JHU TREWS（2026-05 FDA 获批）与 Epic 败例正好构成我们"可解释 + 可调灵敏度"的论据链。

| 产品 | 要点 | 借鉴 |
|---|---|---|

## ④ 警报平台（Alert / Early Warning）⭐ 灵魂类目

| 产品 | 事实 | 对我们的意义 |
|---|---|---|
| **JHU TREWS**（Targeted Real-time Early Warning System） | **2026-05 获 FDA 批准**（hub.jhu.edu 2026-05-12）；提前 2~48 小时识别脓毒症；联邦经费支持，EHR 集成 | 成功案例的标准像：提前量可量化、嵌入工作流、"targeted"= 抑制骚扰 |
| **Epic Sepsis Model（败例）** | 外部验证：灵敏度低、校准差；疫情期警报量 +43%；Nature 2022 多中心研究：医生在警报前多已形成临床怀疑；alert fatigue 是公认死因（PMC10317482） | **答辩金句素材**：黑盒、不可调、高频警报的系统会被临床忽略——PRD 要求"灵敏度可调、权重自定义、可解释"正是 Epic 败因的处方 |
| Cerner EWS/Sepsis Dashboard（加拿大 BC 省） | 护士长 surveillance 视图：按人群监控触发 EWS/脓毒症警报的患者 | 医生端风险看板的直接参照：一屏多名患者、风险排序、未处理警报计数 |
| **PEWS**（儿科早期预警评分） | 护士评分卡：生命体征+症状分维度打分，总分阈值触发响应；MDCalc 有计算器；St. Jude 在拉美推广救活率数据 | sJIA-MAS 的同龄类比：我们的规则引擎=**数字版 PEWS**；分维度打分+总分=天然可解释结构 |

## UI 设计思考（跨五类沉淀）

### A. 双端不是同一界面的两个皮肤
- **患者端 = 消费级**（Bearable/Apple Health 语言）：单手可点、记录 <10 秒、回报是"洞察"（今日简报/相关性/下次门诊问什么）
- **医生端 = 工作流工具**（Doximity/TREWS 语言）：一屏决策、风险排序、证据链一步可达、3 分钟扫完
- 两端共享的是**同一条数据管道**，不是同一张 UI

### B. 警报设计五原则（从 Epic 败例 + TREWS 成功反推）
1. **分级而非轰炸**：silent（记录备查）→ advisory（黄，下次就诊注意）→ urgent（红，建议 24h 内就医）。红色全屏一天弹 3 次就废了
2. **抑制重复**：同一患者同一触发条件在窗口期内只报一次，恶化才升级——TREWS 的 "targeted" 精髓
3. **每条警报 = 证据链卡片**：什么值（铁蛋白 320→1800）+ 越过什么阈值（自定义 3×）+ 持续多久（7 天）+ 依据（2016 PRINTO/ACR/EULAR 原文）+ 建议动作（复核血象/联系主治）
4. **灵敏度可调可见**：滑杆改动时显示"预计警报频率从 X 次/周 → Y 次/周"——把 Epic 的教训变成我们的 UI 功能
5. **警报有生命周期**：触发→已查看→已处理→已解除，列表里能看到"未处理红警 N 条"（Cerner surveillance 视图）

### C. 趋势图三件套
- sparkline 进列表行内（体温/铁蛋白迷你曲线，Cerner 式）
- 详情图带**正常值区间带**（纤维蛋白原 3.6 g/L 画成阈值线）、**事件标记**（发热第 1 天、激素加量、住院）——MAS 故事是"时间轴上的追逐"，事件标记是这个叙事
- 患者 vs 群体中位对照（JHU Malone Center 范式，肌愈通同款文案）

### D. 颜色语义纪律
- 绿/黄/红只表达风险；检验值高低用蓝/灰，绝不用红（红 = 预警专用色，滥用即疲劳）
- 色弱安全：形状+文字标签双编码（▲ 高于阈值 / ▼ 低于阈值）

### E. 可信度标签（医生端信任之本）
- 每行数据带来源徽标：🏥 机构检验 / ✍️ 家属自录 / 🤖 AI 识别待复核——肌愈通三档记录制的医生端呈现

### F. 情绪与无障碍
- 用户是**焦虑的患儿家长**：大字体模式、错误文案说人话（"这条没存上，刷新看看，别急着再记一次"——照抄肌愈通式关怀文案）
- 医生端夜间值班场景：深色模式（病房不刺眼）

### G. 空状态即信息
- "N 周没有记录，趋势正在断档"（肌愈通）比空白图表好；断档本身进入风险计算的置信度
