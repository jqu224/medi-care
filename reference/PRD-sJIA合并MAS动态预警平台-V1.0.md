## 一、项目背景

### 1.1 幼年特发性关节炎全身型（sJIA）

幼年特发性关节炎全身型（systemic juvenile idiopathic arthritis, sJIA）是儿童期最复杂的疾病之一。此类疾病多继发于细菌或病毒感染、恶性肿瘤或其他炎症性疾病，也可能缺乏明确的诱因。

目前 sJIA 主要通过临床表现进行诊断，但往往需要长期随访并根据疾病的后续发展得以最终确诊。在儿童各类慢性关节炎中，sJIA 具有典型的关节外表现特点，这表明 sJIA 是一种全身性疾病。

16 岁以上的儿童或成人也可以发生同样的疾病，称为成人斯蒂尔病（adult-onset Still disease, AOSD）。

| 项目 | 内容 |
|---|---|
| 三大主要临床表现 | 发热、皮疹、关节炎 |
| 突出表现 | 弛张热 |
| 最大风险 | 易并发巨噬细胞活化综合征（MAS），危及生命 |
| 年发病率 | 约 0.3/10 万–0.8/10 万（欧洲研究） |
| 政策地位 | 已纳入中国第二批罕见病目录 |

目前确切的患病率尚不清楚。

- **诊断标准**：2001 年 ILAR 标准与 2019 年 PRINTO 标准（ILAR 要求至少满足 3 项受累关节的多关节炎等；PRINTO 则以不明原因发热等为核心判定依据）。
- **排除要求**：在诊断前需排除感染性疾病、血液肿瘤疾病、风湿免疫性疾病、自身炎症性疾病等。

### 1.2 巨噬细胞活化综合征（MAS）

巨噬细胞活化综合征（MAS）属于继发性嗜血细胞性淋巴组织细胞增多症（HLH），是一种严重且危及生命的过度炎症反应综合征。

可继发于多种儿童风湿性疾病，包括 sJIA、系统性红斑狼疮、幼年皮肌炎、川崎病及自身炎症性疾病——**其中以 sJIA 最为常见，是 sJIA 后果最严重的并发症**。

| 关键数据 | 值 |
|---|---|
| sJIA 患者病程中出现 MAS 的比例 | 至少 7%（并有很多患者仅表现出 MAS 的部分临床特点而未得到诊断） |
| 合并 MAS 的 sJIA 患者致死率 | 在一项纳入超过 350 名 sJIA 相关 MAS 患者的队列中，致死率可达 8% |

MAS 的典型临床特征：快速进展的持续发热、肝脾肿大、淋巴结肿大、肝功能异常（可伴有黄疸，甚至表现为肝功能衰竭）、脑病、紫癜、瘀斑和黏膜出血。

重症患者会出现多器官受累，可能出现呼吸窘迫、肾衰竭、定向障碍、癫痫发作、意识改变、低血压和休克。

### 1.3 核心临床难题

MAS 的不同阶段，临床表现缺乏特异性，尤其是早期表现与 sJIA 不易区分，易错失最佳治疗时机，应用评分标准进行早期诊断尤其困难。

根据最新 2023 年 EULAR 和 PReS 推荐，将持续发热、脾大、SF 升高或上升、血细胞计数异常降低、肝功能异常、血管内凝血激活、血清甘油三酯升高或上升的患者，**均应考虑早期或亚临床 MAS**。

## 二、诊断标准

### 2.1 主流诊断标准（2016 年 PRINTO/ACR/EULAR 联合推出）

当确诊或疑似 sJIA 的患者出现发热的同时具备以下实验室指标时可分类为 MAS：

**必备条件**：铁蛋白 > 684 ng/mL
**并具有以下任意 2 条以上**：

| # | 指标 | 阈值 |
|---|---|---|
| 1 | 血小板 | < 181×10⁹/L |
| 2 | 天门冬氨酸氨基转移酶（AST） | > 48 U/L |
| 3 | 甘油三酯 | > 156 mg/mL |
| 4 | 纤维蛋白原 | < 3.6 mg/dL |

### 2.2 HLH 诊断标准（2004）

符合 8 条中的 5 条：

| 类别 | 指标 |
|---|---|
| 特殊检查 | NK 细胞活性↓、sCD25↑ |
| 病理 | 骨髓、肝脾、淋巴结中发现噬血现象 |
| 临床 | 发热 > 38.5℃（持续 > 1 周）、脾大 |
| 常规检查 | 血细胞减少（累及外周血两系或三系）、甘油三酯（TG）> 3 mmol/L 或纤维蛋白原（Fbg）< 1.5 g/L、铁蛋白 > 500 ug/L |

### 2.3 MAS/sJIA（MS）评分表

公式所含项目及对应系数：

| 评分项目 | 系数 |
|---|---|
| 中枢神经系统受累 | +2.44 |
| 出血现象 | +1.54 |
| 关节炎 | −1.30 |
| 血小板计数 | −0.003 |
| 乳酸脱氢酶（LDH） | +0.001 |
| 纤维蛋白原 | −0.004 |
| 铁蛋白 | +0.0001 |

**判定：若公式计算后 MS 值 ≥ −2.1，则 sJIA 合并 MAS 的可能性大。**

注意：由于将发热作为病情活动的强制指标，因此发热未被列入公式所含项目中。

## 三、产品定位与核心价值

### 3.1 为什么需要预警平台

早期监测 sJIA 合并 MAS 并非依赖某一次检查结果，而是需要密切观察指标动态变化，以尽早诊断、尽早干预。

**现实问题**：地方医生常因缺乏经验，等待指标完全符合诊断标准后再进行干预，在一定程度上延缓了治疗，增加了治疗难度。

因此搭建 MAS 预警平台有助于患者或医生提高警惕，抓住时机。该项目的目的是**动态监测及连续预警**。

### 3.2 产品定位

**sJIA 合并 MAS 动态监测与连续预警平台** —— 通过单次指标评分 + 多次指标动态变化分析，帮助患者或医生早期识别 MAS 风险，抓住治疗时机。

## 四、核心功能需求

### 4.1 预警平台框架

平台分为静态监测与动态监测两条路径，并可结合使用：

- 输入指标
  - 仅输入 1 次指标 → 静态监测（单次指标评分）→ 未达 MAS 阈值 → 结束
  - 输入 ≥ 2 次指标 → 静态监测 + 动态监测 → 分别有不同预警情况

### 4.2 静态监测

| 项目 | 要求 |
|---|---|
| 输入 | 单次指标数值 |
| 输出 | 给出评分 |
| 判定 | 未达到 MAS 阈值则结束 |
| 依据标准 | 2016 PRINTO/ACR/EULAR 标准、2004 HLH 标准、MS 评分表 |

### 4.3 动态监测

| 项目 | 要求 |
|---|---|
| 输入 | 多次指标数值（≥ 2 次） |
| 监测对象 | 指标动态变化趋势（而非单点值） |
| 可设置预警灵敏度 | 用户可调 |
| 可为指标设置权重 | 支持自定义权重 |
| 报警逻辑 | 可设置核心指标和一般指标 |

### 4.4 综合预警

| 输入情况 | 监测方式 | 输出 |
|---|---|---|
| 仅输入 1 次指标 | 静态监测 | 单次评分 |
| 输入 2 次及以上指标 | 静态监测 + 动态监测 | 分别有不同预警情况 |

### 4.5 需要监测的关键指标

依据 2023 年 EULAR/PReS 推荐，以下指标应纳入动态监测范围：

| 类别 | 指标 |
|---|---|
| 临床 | 持续发热、脾大 |
| 炎症标志物 | 铁蛋白（SF）升高或上升 |
| 血液 | 血细胞计数异常降低、血小板计数 |
| 肝功能 | 天门冬氨酸氨基转移酶（AST）等肝功能指标 |
| 凝血 | 血管内凝血激活、纤维蛋白原 |
| 代谢 | 血清甘油三酯升高或上升 |
| 其他 | 乳酸脱氢酶（LDH）、中枢神经系统受累、出血现象、关节炎 |

## 五、非功能需求

| 类别 | 要求 |
|---|---|
| 动态性 | 核心能力是观察指标动态变化，而非单次检查结果 |
| 连续预警 | 支持连续多次输入的累积预警，而非一次性判定 |
| 可配置 | 预警灵敏度、指标权重、核心/一般指标分类均可由用户设置 |
| 可用性 | 面向患者家属与地方医生，需降低使用门槛（地方医生常因缺乏经验延误干预） |
| 时效性 | 目标是尽早诊断、尽早干预，抓住最佳治疗时机 |
| 定位边界 | 辅助预警工具，帮助提高警惕，**不替代专业诊疗判断** |
