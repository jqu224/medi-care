# 这版 MVP 的设计定稿

> 2026-10-07 用户消息原文落盘，作为 ref 存档。配套手稿：`ui-refs/08-mvp三框设计手稿.svg`、`ui-refs/09-mvp设计定稿渲染图.png`。

## 界面	只保留这些

**① 今日 · 患者首页**	顶部头像与问候 「早上好，安安妈妈」；大标题 「安安今天怎么样？」；一条需要关注的变化；最近体温与简洁曲线；用药确认；主按钮 「记录今天」；次入口「给医生看」

**② 快速记录 · 底部弹层**	大数字体温输入，支持手输；症状多选；确认实际服药剂量；底部唯一主按钮 「保存记录」。不拆步骤、不另占一个 Tab

**③ 就诊摘要 · 医患共用页**	近期变化摘要；体温、铁蛋白、血小板分开展示趋势；当前用药；数据来源和更新时间；「导出就诊长图」。授权分享前先预览

预警不单独建中心：融入首页提醒，点击展开触发证据。
我的不占导航：档案与设置收进头像。
先砍掉：医生患者队列、七指标卡片库、AI 问答、灵敏度滑杆及未经验证的“预计警报频率”。

## 视觉方向

暖纸白 #FBF8F3 + 深青绿 #146B60 + 墨色文字；红色只用于异常提醒。
只借你喜欢的 greeting 结构，不沿用整套杂乱仪表盘。
首页上半屏留给问候、状态与下一步行动，不堆功能入口。
采用 390 px 手机画板、24 px 页边距、清晰中文大字、52 px 主按钮。
不做蓝紫渐变、装饰性 DNA、医生头像轮播、层层套卡片。
示例统一标注 「演示数据」；不把“未触发提醒”写成“安全”，预警行动文案待医生审核。
目标画面是安静、温暖、信息明确的照护工具，而不是缩小的医院后台。
