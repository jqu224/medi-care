# 医患平台竞品调研（2026-10-05）

> 目的：为项目7（sJIA + MAS 动态预警平台）双端（患者端 + 医生端）做界面与信息架构参考。
> 方法：anysearch extract + 前端 bundle 逆向（肌愈通）+ 背景检索。医生可读（医患端）是重点。
> 结论先行：**肌愈通（ai.fshdyouth.com）是同赛事 FSHD 组织的姊妹平台，是本次最重要的设计标尺**；蓝鲸医生是「双端结构」的祖师爷；协和医生端 App + NRDR 论文是「医生端该长什么样」的权威参照。

## 一、五个指定站点逐一档案

### 1. 肌愈通 —— ai.fshdyouth.com（最重要 ⭐）

| 项 | 内容 |
|---|---|
| 全名 | 肌愈通 — FSHD 患者自我管理（"智能 FSHD 管理平台"） |
| 组织 | FSHD 青年（fshdyouth.com，同赛事项目8 FSHD 辅具同一主办方） |
| 形态 | Expo + React Native Web 的 SPA（单 bundle 3.5 MB），登录墙，密码/验证码登录 |
| 定位 | 面肩肱型肌营养不良（FSHD）患者自我管理：记录症状与肌力变化、整理化验单和检查报告、查阅带出处的疾病知识 |
| 视觉 | theme-color `#FBF8F3`（暖纸白底，亲和病友共建风，非医院冷蓝） |

**功能全景（从 bundle 文案逆向，按模块）**：

- **今日简报（AI）**：每天生成"最近的变化 / 记录节奏 / 下次门诊可以提什么"；时间感知问候（夜深了/早上好…）；新用户引导"再记录几次就告诉你变化在哪"
- **日常记录**：秒级记录（上楼用时、睡眠、跌倒次数）；趋势曲线从第二条开始出现；断档提醒（"N 周没有记录，趋势正在断档"）
- **肌力自测**：16 个肌群分组（三角肌/肱二头/肱三头/胫前肌/股四头/腘绳肌 + 肩带/上臂前后群/躯干侧/臀肌/大腿前后群/小腿前后群），三档记录制：
  - 标准档（严格按卡片场地/姿势/口令 → 进趋势线）
  - 条件不完整（照做但有偏差 → 存、显示，不进趋势线）
  - 自由记录（随手记 → 是数据但不进趋势线）
  - 每档都有"这什么意思/这项测试的出处"的解释层；明标"不是已发表量表，只和你自己上一次比"
- **检查报告**：拍照上传 → AI 识别指标 → 自动归类（基因/肺功能/生化/肌酶/甲功/凝血/门诊病历/出院记录/入院记录/病程记录）→ "患者版摘要通俗解读" → 关键证据分栏展示
- **临床护照**：核心概念——"把你的记录整理成神经科医生要看的那份，带去协作网医院"；不展示原始数据堆叠，只告诉用户"接下来更该补什么、看什么"
- **病友群体对比**：完成肌力自测后与群体中位数对比（"病友数据还不够，暂不做对比"的降级文案）
- **AI 问答**：医学知识库检索 + 授权后引用本人档案报告；每条回答标明引用来源；隐私模式可切；"回答仅供参考，不能替代医生诊断"
- **我的随访计划**："按指南，结合你已录入的信息，哪些检查值得和医生确认"
- **跌倒记录**：单独事件记录 + 从日常记录里聚合次数；两次以上跌倒触发安全提示（"走的这两项请务必有人全程跟着"）
- **用药与辅具**：当前用药清单、添加用药
- **时间轴**：病程事件、报告、记录按时间统一排列
- **隐私与合规**：知情同意历史（consent/history 路由）、隐私授权开关、数据导出（JSON 全档案）、注销 7 天冷静期、撤回授权后数据保留
- **无障碍**：大字体、语音读屏、高对比度
- **管理端**：`/p-admin`（调用量 + 患者列表）、`/ai/audit`（AI 审计）

**可借鉴点（对我们的映射）**：
1. 「临床护照」→ 我们的**门诊摘要卡**：患者日常记录自动整理成"地方医生/风湿科门诊可读的一页纸"，正是 PRD 里"改变地方医生等标准全符合才干预"的载体
2. 三档记录制 + "进不进趋势线"的显式规则 → 家属在家测的数据质量参差，必须有同款"可信/存疑"分级，否则医生端趋势图不可信
3. 每个功能旁都有"为什么/出处"解释层 → 呼应 PRD"预警可解释"要求
4. 群体对照（患者中位）→ 医生端单患者 vs 群体分布视图
5. 隐私授权链路 → 演示时"患者授权后才推送给医生"的叙事

## 三、对项目7「医生端」的启示（要素清单）

按"医生可读"优先级排：

1. **风险分层患者列表**（绿/黄/红 + 每行显示触发原因摘要，点进去看完整解释）——协和医生端 + PRD 双要求
2. **单患者时间线 + 趋势图**：体温曲线、血象、铁蛋白、纤维蛋白原、AST、TG、LDH（PRD 指标口径），发热持续天数必须一眼可见
3. **门诊摘要卡（患者端生成 → 医生端打开）**：照抄肌愈通"临床护照"思路， named 「就诊一页通」：基础档案、当前用药、近期异常、我该问医生什么
4. **可解释预警面板**：触发规则逐条列出（"铁蛋白 7 天内从 320 → 1800，超过自定义阈值 3 倍" + 依据=2016 PRINTO/ACR/EULAR）——HLH-2004 / MS 评分原文引用，灵敏度/权重可调入口放在这页
5. **数据可信度分级**：患者自录数据标"家属自测/未复核"，检验科数据标"机构报告"——肌愈通三档记录制的医生端对应物
6. **授权状态指示**：哪些数据是患者家属主动授权共享的（隐私合规叙事）
7. **检查建议生成**："按 2023 EULAR/PReS 口径，该患儿距上次铁蛋白检测已 6 周"——肌愈通"随访计划"的医生端镜像
8. **免责条常驻**："辅助预警 ≠ 诊断工具，不替代专业诊疗判断"
