# 项目7：sJIA + 合并 MAS 动态预警平台

> 官方名称：项目7：sJIA + 合并 MAS 动态预警平台
> sJIA = 全身型幼年特发性关节炎；MAS = 巨噬细胞活化综合征（sJIA 最凶险的合并症，可迅速致命，**早识别是救治关键**）
> 用户口径：罕见病信息管理（分患者端和医生端）——软件项目，**本次黑客松主力**

## 交付定位

双端 Web 应用（患者端 + 医生端）+ MAS 动态预警规则引擎 + 演示数据：

### 患者端
- 每日症状/体温/用药记录（少即是多：sJIA 日常监测核心字段）
- 异常提醒：引导「立即就医」而非自行观察
- 就诊时一键生成病情时间线给医生

### 医生端
- 患者列表 + 风险分层看板（绿/黄/红）
- 单患者动态趋势图（体温曲线、血象、铁蛋白等 MAS 相关指标）
- 预警规则引擎：HLH-2004 / sJIA-MAS 临床要点转成可解释规则（发热持续、血象下滑、铁蛋白飙升、纤维蛋白原下跌等），触发时高亮 + 推送
- 每条预警可解释：「为什么报警」比「报了个警」重要（评审加分点）

### 技术形态（初稿，可改）
- 前端：React + Tailwind（本仓库已有 webapp-building 工作流）
- 后端/数据：演示期可用本地 SQLite + 种子数据，或轻量 FastAPI
- 演示数据：编造 3-5 个虚拟患儿轨迹，其中 1 个埋了 MAS 前兆（现场演示预警弹出的戏剧性）
